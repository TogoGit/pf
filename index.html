Five projects, examined the way an engagement would be — target, method, outcome. Cinq projets, traités comme le serait un engagement — cible, méthode, résultat.

TG-01 SEPA

Target: coordinate multi-step penetration testing campaigns without juggling a dozen disconnected scripts. Cible : piloter des campagnes de pentest multi-étapes sans jongler entre une dizaine de scripts déconnectés.

Telegram→ Redis Queue→ Docker Workers→ PostgreSQL

A pentest orchestration system controlled entirely from Telegram. Commands are queued through Redis, picked up by containerized workers, and every action is logged in structured form to PostgreSQL — a full engagement can be triggered, tracked, and audited from a phone.

Système d'orchestration de pentest piloté entièrement depuis Telegram. Les commandes passent par une file Redis, sont récupérées par des workers conteneurisés, et chaque action est journalisée de façon structurée dans PostgreSQL — un engagement complet peut être déclenché, suivi et audité depuis un téléphone.

PythonDockerRedis PostgreSQLn8nstructlog
TG-02 DAST Recon AgentAgent de recon DAST

Target: turn hours of manual reconnaissance into one repeatable pipeline. Cible : transformer des heures de reconnaissance manuelle en un pipeline unique et reproductible.

subfinder→ httpx→ naabu→ ffuf→ nmap

A containerized recon pipeline built on the ProjectDiscovery toolchain. Subdomain enumeration feeds live-host probing, which feeds port discovery, fuzzing, and service scanning — one command instead of five tools run by hand.

Pipeline de reconnaissance conteneurisé bâti sur la suite ProjectDiscovery. L'énumération de sous-domaines alimente la détection d'hôtes actifs, qui alimente la découverte de ports, le fuzzing et le scan de services — une seule commande au lieu de cinq outils lancés à la main.

Dockersubfinderhttpx naabuffufnmap
TG-03 Email OSINT ToolkitToolkit OSINT email

Target: consolidate email exposure and reputation checks normally spread across five separate tools. Cible : regrouper les vérifications d'exposition et de réputation d'une adresse email, réparties d'habitude sur cinq outils différents.

holehe→ sherlock→ h8mail→ Shodan→ GHunt

A single toolkit that runs an email address through breach data, account-existence checks, and infrastructure lookups in one pass — built to speed up the OSINT phase of an engagement.

Un toolkit unique qui fait passer une adresse email par des vérifications de fuites de données, d'existence de comptes et de lookups infrastructure en une seule passe — pensé pour accélérer la phase OSINT d'un engagement.

Pythonholehesherlock h8mailShodanGHunt
TG-04 TryHackMe CTFCTF TryHackMe

Target: a Flask/Werkzeug web app hiding admin access behind three separate weaknesses. Cible : une application web Flask/Werkzeug cachant un accès admin derrière trois faiblesses distinctes.

LFI→ Session Cookie ForgeryForge de cookie→ Exposed API KeyClé API exposée→ Admin AccessAccès admin

Chained a local file inclusion into forging a valid session cookie, then found an admin API key hardcoded in the application's source — three individually minor issues, one full administrative takeover.

Enchaînement d'une inclusion de fichier local pour forger un cookie de session valide, puis découverte d'une clé API admin codée en dur dans le code source — trois failles mineures prises séparément, une prise de contrôle administrateur complète une fois combinées.

TG-05 Job Market ScraperScraper marché de l'emploi

OAuth2→ France Travail APIAPI France Travail→ FilteringFiltrage→ Structured StorageStockage structuré

An OAuth-authenticated scraper against the France Travail API, automating job-market monitoring end to end. The same instinct for structured, repeatable process as the security tooling above — just pointed at a business problem instead of a target host.

Scraper authentifié OAuth sur l'API France Travail, automatisant la veille emploi de bout en bout. Le même réflexe de processus structuré et reproductible que dans les outils de sécu ci-dessus — appliqué cette fois à un problème business plutôt qu'à une cible technique.
